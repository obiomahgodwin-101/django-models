# Django Models & Views Project

## Overview
This project demonstrates advanced Django concepts including:
- ForeignKey, ManyToMany, and OneToOne relationships
- Function-based and class-based views
- User authentication and registration
- Role-based access control and custom permissions

## Features
- Users can register, login, and logout
- Role-based permissions for adding, editing, and deleting books
- Superuser/admin can manage users, roles, and permissions
- Complex relationships: Author → Book → Library → Librarian
